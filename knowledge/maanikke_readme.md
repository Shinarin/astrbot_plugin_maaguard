## 使用前必读

- 本程序仅能满足绝大部分养老号的需求。开荒阶段、功能未解锁或关卡打不过，建议暂时不要使用。
- 程序旨在免去每日任务的重复操作，若希望培养顶级战力号，还请多上线微操。

### 环境要求

- Windows 10/11（64 位），NIKKE 国服桌面端，账号由 WeGame 登录启动。
- 必须安装 Python（3.10 及以上），安装时务必勾选 "Add Python to PATH"，否则 agent 无法启动。
- 首次启动 agent 时会自动安装 maafw 与 Pillow（需联网；网络不佳自动切换清华镜像；已装其他 5.x 版本 maafw 会直接复用）。
- MaaNikke.exe 及各启动脚本均需右键以管理员身份运行。
- 方案 B（全程自动化）还需安装 AutoHotkey 2.0。

### 游戏内设置（务必完成）

1. 过场动画改为简化版或关闭。
2. 画质按 README 图示修改（务必）。
3. 动态壁纸播放建议关闭，防止莫名 bug。
4. 使用 MaaNikke 前，先手动完成过一次每日。
5. 务必把战斗模式默认开启自动。

## 安装与更新

- 完整程序（含 GUI，解压即用）去 Releases 下载最新版本；仓库仅含自定义层源码（agent / resource / interface）。
- 解压 zip 到任意目录（建议不要过多层级嵌套）。
- 若双击 MaaNikke.exe 无法启动（缺 dll / 运行时），右键管理员运行 DependencySetup_依赖库安装_win.bat，装完重启电脑。
- 版本更新时替换 agent、interface.json、resource 这三个文件（建议先删原文件再复制）。

## 程序组成

| 文件 | 作用 |
| ---- | ---- |
| MaaNikke.exe | GUI 主程序：任务勾选/配置界面，每日任务的实际执行者 |
| autoMaaNikke.bat | 一键全流程：拉起游戏 → 运行每日任务 → 守候到结束 |
| autoMaaNikke.py | 上面 bat 的 Python 等价版，供任务调度器（如 OneDragon ScriptChainer）接入 |
| startnikke.ahk | 自动打开 WeGame 并点击"启动"，把游戏拉起到 nikke.exe 运行 |
| DependencySetup_依赖库安装_win.bat | 安装 VC++ 运行库与 .NET Desktop Runtime（MaaNikke.exe 打不开时用） |
| launcher_cache.txt | 启动器路径缓存，勿手动编辑 |
| interface.json | 任务清单与选项定义（GUI 启动时读取，普通用户无需改动） |
| config/、logs/ | GUI 配置与运行日志（出问题时排查用） |

方案 B 启动链：autoMaaNikke.bat/.py（管理员运行）→ ① 调用 startnikke.ahk 拉起游戏 → ② 每 10 秒检查 nikke.exe，不在则重拉 → ③ 启动 MaaNikke.exe，GUI 自动执行勾选的任务 → ④ 每 10 秒守候 MaaNikke.exe 退出（任务跑完自动关闭）→ 脚本结束。脚本不会主动杀游戏进程。

## 使用方法

方案 A（手动版）：自行打开 WeGame 启动 Nikke 进入大厅 → 管理员运行 MaaNikke.exe → 勾选任务点开始 → 回来即完成。

方案 B（全程自动化）：安装 AutoHotkey 2.0（必须 v2）→ 用 Windows 任务计划程序定时启动 autoMaaNikke.bat（任务属性里勾选"最高权限运行"）→ MaaNikke.exe 设置：启动后操作选"仅启动脚本"（Nikke 必须由 WeGame 启动，选"启动游戏"无效）→ 可选：结束后操作设为"关闭目标程序和本程序"，任务跑完自动闭环。保持电脑开机即可定时全自动跑完每日。

startnikke.ahk 说明：游戏已在运行则静默退出；按优先级定位 WeGame 启动器（launcher_cache.txt 缓存 → nikke.exe 进程反查 → 遍历硬盘搜索 → 弹窗让用户手动启动一次后自动记路径）；打开启动器固定窗口 1600×900 后按比例点击"启动"，最多重试 3 次×2 轮；检测到错误/更新失败/网络异常弹窗则退出并红色托盘提示需人工处理。游戏换安装目录后删掉 launcher_cache.txt 即可重建缓存。WeGame 改版点不到按钮时，调 ahk 配置区的 BTN_RATIO_X / BTN_RATIO_Y。

## 功能列表

启动游戏；登录奖励、邮件领取、每日/每周奖励、PASS 奖励；付费商店领取、道具商店每日购买；前哨防御、派遣公告栏、咨询和送礼、装备升级、好友点数收取赠送、社交点招募；模拟室、竞技场、拦截战、爬塔、协同作战、单人突击、联盟突袭(beta)、更生馆；同步器和循环室；大型活动（不定时随版本更新）。

任务选项要点：

- 道具商店每日购买：普通/躯体标签/废铁商店开关；竞技场通用道具可细选风/火/电/物理/水代码、代码手册宝箱、企业装备熔炉。
- 前哨防御：可选钻石一举歼灭（默认关，只用每日免费 1 次），开启后可设连续歼灭次数 1-11。
- 派遣公告栏：需游戏内已解锁自动派遣。
- 咨询和送礼：需手动咨询的 3 个妮姬请收藏至顶端。
- 装备升级：无法指定装备，仓库需至少一件未满级装备。
- 模拟室：需已通关最后一个模拟室、解锁快速模拟。
- 竞技场：纯自动战斗；特殊竞技场可设只领奖励不战斗。
- 拦截战：周一手操 boss 战开关；特殊拦截战 boss 默认克拉肯，其他 boss 识别失败率较高，谨慎选择。
- 爬塔：无限之塔开关及每日次数（别太高，会拉长耗时）；企业塔四个企业单独开关。企业塔未选"打满"时每天按优先级爬一个开启中的企业塔（朝圣者/超标准 > 泰特拉 > 米西利斯 > 极乐净土）。
- 协同作战：打满三次，可能不稳定，出错不影响其他每日。
- 联盟突袭(beta)：不稳定，默认不勾选。
- 更生馆：识别困难，如无必要建议不勾选；特定节点弹对话、识别耗时较长属正常。
- 同步器和循环室：可选是否使用时间盒子道具。
- 限时活动：商店兑换暂定专票、普票、红眼盒子 2h、红眼。

## 常见问题

- MaaNikke.exe 双击没反应 / 报缺运行时：管理员运行 DependencySetup_依赖库安装_win.bat，装完重启电脑。
- agent 启动失败 / 找不到 Python：安装 Python 时必须勾选 "Add Python to PATH"；终端执行 python --version 能输出版本号才行。
- startnikke.ahk 找不到启动器路径：按弹窗提示在 WeGame 手动启动一次游戏，脚本会自动缓存路径，之后秒级定位。
- 游戏换安装目录后找不到：删除 launcher_cache.txt，下次运行自动重建。
- WeGame 更新后点不到"启动"：调整 startnikke.ahk 配置区的 BTN_RATIO_X / BTN_RATIO_Y。
- 游戏重启/加载期日志刷"截图用时过长"且截图全黑：加载期不产帧，属正常现象，进大厅后自愈，不用处理。
- 任务跑到一半卡住或异常：先看游戏窗口是否被最小化/遮挡、画质设置是否被改动；日志在 logs/ 目录（log-*.log 为 GUI 日志，maafw.log 为底层识别日志，vision/ 存识别截图），排查时提供这些文件。
- 不要同时运行多个 MaaNikke 实例（开发版与正式版双开会互踩文件锁导致异常）。

## 日志位置

- GUI 日志：logs/log-YYYYMMDD.log（agent 输出混在 [src=Agent] 行）
- 原生日志：logs/maafw.log、debug/maafw.log（识别分数、节点流转、截图细节）
- 识别截图：logs/vision/；错误存档：logs/on_error/
